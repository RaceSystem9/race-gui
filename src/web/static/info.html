안내

이 페이지는 무엇인가요?

대회 운영 PC(레이스 컨트롤 프로그램)에서 실시간으로 제공하는 경주 진행 상황과 순위 정보를 웹 브라우저로 볼 수 있도록 만든 방송용 페이지입니다. 약 0.5초마다 자동으로 최신 정보로 갱신됩니다.

메뉴 안내

  • 실시간 경주: 현재 진행 중인 팀의 타이머, 신호등, Lap 기록, 미션 점수를 보여줍니다.
  • 순위표: 1차 / 2차 / 최종 순위를 탭으로 전환하며 볼 수 있습니다.
  • 참가팀: 전체 참가팀 목록과 라운드별 진행 상태(완료/미완료)를 보여줍니다.

연결이 끊겼다고 나올 때

상단의 연결 상태 표시가 "연결 끊김"으로 바뀌면 레이스 컨트롤 PC와의 네트워크 연결이나 해당 프로그램 실행 상태를 확인해 주세요. 네트워크가 복구되면 자동으로 다시 연결됩니다.

약 0.5초마다 자동 갱신됩니다.
